# Kurenai Studio 安装方法

本文说明如何从 GitHub 克隆 Kurenai，安装依赖，并验证 `kurenai` CLI 可用。  
Kurenai **不会**发布到 npm，请始终从源码安装。

更多背景见英文 [README.md](../README.md)；参与 Swarm 协作见 [SWARM.md](SWARM.md)。

## 一句话安装（给 Agent）

把下面整段丢给任务 Agent，让它自学安装并用 kurenai 开发 Cocos 游戏：

```text
自学并只用最新 kurenai（https://github.com/kurenai-studio/kurenai：clone 后 Node.js 22+ 下 `npm install && npm link`；不要单独安装完整 cocos-cli / PinK）开发 Cocos 游戏：`kurenai init` → `host start` → 按项目 `AGENTS.md` 只改 `assets/game/` 与 `assets/resources/`，用 `asset info` / `logs` / `context` 闭环，禁止手写 .meta、prefab 不挂脚本；交付时再 `kurenai publish --platform web-desktop`。
```

目标形态：**完全不依赖用户单独装 cocos-cli / PinK**。运行时即仓库内 `vendor/cocos-core`。

人手动安装按下文逐步操作即可。

## 1. 准备环境

请先准备：

- **Node.js 22+** 与 npm
- 可访问 GitHub 的网络
- **不要**安装 PinK / 完整 cocos-cli（见下文「cocos 运行时」）

检查版本：

```powershell
node --version
npm --version
```

macOS / Linux 可使用 `bash` 或 `zsh`，命令与下方 PowerShell 示例等价（环境变量写法不同即可）。

## 2. 克隆并安装

```powershell
git clone https://github.com/kurenai-studio/kurenai.git
Set-Location kurenai
npm install
```

仓库已包含编译产物 `lib/`，**无需**额外 build 即可使用 CLI。

可选：将 `kurenai` 加入全局 PATH：

```powershell
npm link
```

不 link 时，可在仓库根目录用：

```powershell
node bin/kurenai.mjs --help
```

## 3. cocos 运行时（包内源码）

裁剪后的运行时就是仓库里的 **`vendor/cocos-core`** 源码树（不是旁路 tgz）。

- `npm install` → `postinstall` 只负责在该目录装 `node_modules`
- 维护者从完整安装刷新：`npm run vendor:cocos`
- **不要**安装 PinK / 完整 cocos-cli

裁剪规则见 [cocos-cli-split.md](cocos-cli-split.md)（维护者文档）。

## 4. 验证安装

在仓库根目录或已 `npm link` 的全局环境中：

```powershell
kurenai --help
```

或：

```powershell
node bin/kurenai.mjs --help
```

应看到子命令列表（如 `init`、`host`、`asset`、`logs`、`context`、`publish` 等）。

在任意空目录试初始化模板（可选）：

```powershell
kurenai init .\my-game --template base-ai
```

## 5. 更新

在克隆目录内拉取最新代码并重新安装依赖：

```powershell
Set-Location D:\path\to\kurenai
git pull
npm install
```

若曾执行 `npm link`，更新后一般无需重复 link。

## 常见问题

### 找不到 `kurenai` 命令

确认已 `npm link`，或使用 `node bin/kurenai.mjs`；检查 npm 全局 bin 目录是否在 `PATH` 中。

### Host 启动失败或找不到 cocos 运行时

确认 `vendor/cocos-core/dist/cli.js` 存在；缺的话跑 `npm run vendor:cocos`。不要去装 PinK。
