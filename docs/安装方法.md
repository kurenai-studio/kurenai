# Kurenai Studio 安装方法

本文以 Windows PowerShell 为例，说明如何从零安装 DSH 和 Kurenai Studio。

## 1. 准备环境

请先安装：

- Node.js 和 npm
- 可访问 npm 与 GitHub 的网络环境
- 一份可用的 [headless-cocos](https://github.com/shinjiyu/headless-cocos) 本地目录

检查 Node.js 与 npm：

```powershell
node --version
npm --version
```

## 2. 安装 DSH

全局安装最新版 DSH：

```powershell
npm install --global @deepseek-ai/dsh@latest
dsh --version
```

首次启动 Web 界面，让 DSH 创建默认的 `web` Profile：

```powershell
dsh web
```

看到终端输出访问地址后，说明 DSH 安装成功。按 `Ctrl+C` 停止本次启动，再继续安装插件。

## 3. 安装 Kurenai 插件

通过 DSH 插件管理器从 GitHub 安装：

```powershell
dsh plugin --profile web add "https://github.com/kurenai-studio/kurenai.git#main"
```

安装完成后，Kurenai 会自动加入 DSH 的 `web` Profile，不需要手动修改 DSH 配置文件。

## 4. 配置 Headless Cocos

Kurenai 不内置 Cocos Creator 引擎和运行时文件，需要通过环境变量指定本地 `headless-cocos` 根目录。

仅对当前 PowerShell 窗口生效：

```powershell
$env:KURENAI_HEADLESS_ROOT = "D:\path\to\headless-cocos"
```

永久写入当前 Windows 用户环境变量：

```powershell
[Environment]::SetEnvironmentVariable(
  "KURENAI_HEADLESS_ROOT",
  "D:\path\to\headless-cocos",
  "User"
)
```

永久设置后，请重新打开 PowerShell。

> `headless-cocos` 的 Runtime Kit 和 Cocos 引擎文件需按照该仓库的说明单独准备，并遵守 Cocos Creator 的许可要求。

## 5. 启动

进入准备工作的项目目录，然后启动 DSH：

```powershell
Set-Location "D:\path\to\your-cocos-project"
dsh web
```

默认访问地址通常为：

```text
http://127.0.0.1:3088
```

DSH 的会话工作目录（`cwd`）就是 Kurenai 当前操作的 Cocos 项目目录。Kurenai 不维护另一套项目路径。

## 6. 验证安装

打开 DSH 后，完成以下检查：

1. 创建或打开一个会话。
2. 确认会话工作目录是目标 Cocos 项目目录。
3. 点击界面中的 **Kurenai** 入口。
4. 空目录应显示 2D/3D 初始化选项；已有工程应显示启动预览入口。
5. 启动后应看到实时预览、场景节点树和 Inspector 区域。

## 7. 更新或重装插件

```powershell
dsh plugin --profile web remove "@kurenai-studio/dsh-plugin-kurenai"
dsh plugin --profile web add "https://github.com/kurenai-studio/kurenai.git#main"
```

更新后重新启动 DSH。

## 常见问题

### 找不到 `dsh` 命令

重新打开 PowerShell，并确认 npm 的全局可执行目录已经加入 `PATH`。

### 提示 `KURENAI_HEADLESS_ROOT` 未配置

确认环境变量指向 `headless-cocos` 仓库根目录，并在设置永久环境变量后重新打开终端。

### 端口被占用

为 DSH 指定其他端口：

```powershell
dsh web --port 3090
```

### Kurenai 打开的不是预期项目

检查当前 DSH 会话的工作目录。Kurenai 始终使用会话的 `cwd`，而不是 DSH Profile 目录或插件安装目录。
