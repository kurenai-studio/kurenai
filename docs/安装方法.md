# Kurenai Studio 安装方法

本文说明如何从 GitHub 克隆 Kurenai，安装依赖，并验证 `kurenai` CLI 可用。  
Kurenai **不会**发布到 npm，请始终从源码安装。

更多背景见英文 [README.md](../README.md)；参与 Swarm 协作见 [SWARM.md](SWARM.md)。

## 一句话安装（给 Agent）

把下面整段丢给任务 Agent，让它自学安装并用 kurenai 开发 Cocos 游戏：

```text
自学并只用最新 kurenai（https://github.com/kurenai-studio/kurenai：clone 后 Node.js 22+ 下 `npm install && npm link`；预览/构建所需的精简 cocos 运行时由 kurenai 按需拉取，不要单独安装完整 cocos-cli / PinK）开发 Cocos 游戏：`kurenai init` → `host start` → 按项目 `AGENTS.md` 只改 `assets/game/` 与 `assets/resources/`，用 `asset info` / `logs` / `context` 闭环，禁止手写 .meta、prefab 不挂脚本；交付时再 `kurenai publish --platform web-desktop`。
```

目标形态：**不依赖用户单独装 cocos-cli**。Kurenai 分发删减后的 web `core`（及按需的 platform/native 包）。当前代码里的 PinK / `KURENAI_COCOS_CLI_ROOT` 只是过渡，不是产品口径。

人手动安装仍按下文逐步操作即可（过渡期若本机已有 PinK，仍可先跑通）。

## 1. 准备环境

请先准备：

- **Node.js 22+** 与 npm
- 可访问 GitHub 的网络
- **cocos-cli**（Cocos 预览与资源管线依赖；见下文「配置 cocos-cli」）

检查版本：

```powershell
node --version
npm --version
```

macOS / Linux 可使用 `bash` 或 `zsh`，命令与下方 PowerShell 示例等价（环境变量写法不同即可）。

## 2. 克隆并安装

```powershell
git clone https://github.com/kurenai-studio/kurenai.git
Set-Location kurenai
npm install
```

仓库已包含编译产物 `lib/`，**无需**额外 build 即可使用 CLI。

可选：将 `kurenai` 加入全局 PATH：

```powershell
npm link
```

不 link 时，可在仓库根目录用：

```powershell
node bin/kurenai.mjs --help
```

## 3. 配置 cocos-cli

预览 Host 使用 [cocos-cli](https://github.com/SUD-GLOBAL/cocos-cli) 的运行时、asset-db 与脚本打包能力。

- **默认路径**（macOS）：PinK 安装的  
  `~/Library/Application Support/cocos-default/cocos-4.0.0-alpha.33`
- **自定义路径**：设置环境变量 `KURENAI_COCOS_CLI_ROOT` 指向 cocos-cli 根目录

仅对当前 PowerShell 会话生效：

```powershell
$env:KURENAI_COCOS_CLI_ROOT = "D:\path\to\cocos-cli"
```

永久写入当前 Windows 用户环境变量：

```powershell
[Environment]::SetEnvironmentVariable(
  "KURENAI_COCOS_CLI_ROOT",
  "D:\path\to\cocos-cli",
  "User"
)
```

macOS / Linux 示例：

```bash
export KURENAI_COCOS_CLI_ROOT="$HOME/path/to/cocos-cli"
```

Host 会调用 cocos-cli 内部模块，请保持与项目 PinK / 文档一致的 **版本 pinned**，避免随意升级。

按需拆包（core / platform / native，面向 webgame 先装 ~1.7 GB core）见 [cocos-cli-split.md](cocos-cli-split.md)。

> 旧版文档中的 DSH 插件、`headless-cocos` 与 `KURENAI_HEADLESS_ROOT` 已废弃，见 [cocos-cli-migration.md](cocos-cli-migration.md)。

## 4. 验证安装

在仓库根目录或已 `npm link` 的全局环境中：

```powershell
kurenai --help
```

或：

```powershell
node bin/kurenai.mjs --help
```

应看到子命令列表（如 `init`、`host`、`asset`、`logs`、`context`、`publish` 等）。

在任意空目录试初始化模板（可选）：

```powershell
kurenai init .\my-game --template base-ai
```

## 5. 更新

在克隆目录内拉取最新代码并重新安装依赖：

```powershell
Set-Location D:\path\to\kurenai
git pull
npm install
```

若曾执行 `npm link`，更新后一般无需重复 link。

## 常见问题

### 找不到 `kurenai` 命令

确认已 `npm link`，或使用 `node bin/kurenai.mjs`；检查 npm 全局 bin 目录是否在 `PATH` 中。

### Host 启动失败或找不到 cocos-cli

检查 `KURENAI_COCOS_CLI_ROOT` 是否指向有效的 cocos-cli 安装根目录；macOS 用户可先确认 PinK 默认路径是否存在。
