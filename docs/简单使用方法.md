# Kurenai Studio 简单使用方法

Kurenai Studio 把 DSH 对话、Headless Cocos 实时预览、场景节点树和 Inspector 放在同一个工作界面中。你可以一边与 Agent 对话，一边查看和选择游戏中的节点。

## 一、创建新工程

1. 新建一个空目录。
2. 在该目录中启动 DSH：

   ```powershell
   Set-Location "D:\path\to\empty-project"
   dsh web
   ```

3. 在 DSH 中创建新会话，确认会话工作目录是这个空目录。
4. 点击 **Kurenai** 打开工作台。
5. 选择初始化模板：
   - **2D**：`base-ai`
   - **3D**：`base-ai-3d`
6. 等待初始化和预览启动完成。

不要把 DSH 的安装目录、Profile 目录当作工程目录。Kurenai 只操作当前会话的工作目录。

## 二、打开已有工程

已有工程的根目录应包含可识别的 `package.json`。

```powershell
Set-Location "D:\path\to\existing-project"
dsh web
```

进入 DSH 后：

1. 创建或继续该工程对应的会话。
2. 点击 **Kurenai**。
3. 点击启动预览。
4. 等待右侧出现 Cocos 画面和节点树。

下次继续工作时，重新打开同一个 Workspace 或会话即可。

## 三、基本工作方式

推荐循环如下：

1. 在预览画面或节点树中点击目标节点。
2. Kurenai 获取节点名称、路径和组件等信息。
3. 在对话中说明希望如何修改。
4. Agent 修改工程源文件。
5. Headless Cocos 重新编译，并把结果刷新到预览中。
6. 查看结果，继续提出调整要求。

示例：

```text
把当前选中的按钮放大 15%，背景改成蓝色，保留原有点击逻辑。
```

```text
为当前选中的节点增加一个从下向上弹出的入场动画，时长 0.3 秒。
```

```text
检查当前选中节点为什么没有显示，并直接修复源文件。
```

## 四、界面操作

### Hide

只隐藏 Kurenai 工作台，不停止 Headless Cocos 预览。再次点击 Kurenai 可以快速恢复。

### Stop

停止当前预览进程并关闭工作台。需要继续时重新启动预览。

### 拖动分隔线

拖动对话区和 Kurenai 工作台之间的分隔线，可以调整两侧宽度。宽度会保存在当前浏览器中。

### 选择节点

可以从预览画面或节点树选择节点。选中信息会同步给当前 DSH 会话，帮助 Agent 明确正在操作的对象。

## 五、让 Agent 更高效

- 一个会话尽量只对应一个工程目录。
- 修改前先选中目标节点，减少名称歧义。
- 说明期望结果，不必指定每一行代码怎么写。
- 如果修改涉及多个节点，明确它们的层级或交互关系。
- 让 Agent 修改源文件，不要只修改浏览器中的临时运行状态。
- 项目中的 `AGENT_AUTHORING.md` 和相关 Skill 会为 Agent 提供 Headless Cocos 编写规则。

## 六、预览没有立即更新

先等待当前编译完成。如果仍未刷新：

1. 确认 Agent 已保存源文件。
2. 查看 DSH 或 Headless Cocos 终端是否有编译错误。
3. 使用 **Stop** 停止预览，再重新启动。
4. 若脚本组件未生效，检查场景或 Prefab 中的自定义组件 Class ID 是否使用编译产物注册的压缩 ID，而不是 `.meta` 中的完整 UUID。

## 七、结束工作

- 暂时离开但希望保留预览：点击 **Hide**。
- 确定不再使用当前预览：点击 **Stop**。
- 关闭 DSH：回到启动 DSH 的终端并按 `Ctrl+C`。
