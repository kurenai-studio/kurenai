# OpenPaaS 文档

## 平台简介

面向开发者的全平台游戏分发与应用内发行解决方案。

基于 COCOS 引擎、Creator、PinK AI IDE 与统一 Runtime 能力，OpenPaaS 帮助开发者实现 一次开发、统一打包、多平台运行、多场景分发。开发者可免费入驻，快速接入全球3000+流量平台，覆盖 25+ 亿终端用户。降低适配与发行成本，提升上线效率和商业转化。

让开发更简单，让分发更高效。
