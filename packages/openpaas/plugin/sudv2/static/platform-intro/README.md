# OpenPaaS Documentation

## Platform Overview

A cross-platform game distribution and in-app publishing solution for developers.

Built on the COCOS engine, Creator, PinK AI IDE, and unified Runtime capabilities, OpenPaaS helps developers achieve one-time development, unified packaging, multi-platform runtime support, and multi-scenario distribution. Developers can join for free, quickly access 3,000+ traffic platforms worldwide, and reach more than 2.5 billion end users. It reduces adaptation and publishing costs while improving launch efficiency and commercial conversion.

Make development easier and distribution more efficient.
