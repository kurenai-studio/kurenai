# Platform Overview

WeChat Mini Game is a lightweight game distribution platform built on the WeChat ecosystem. No download or installation is required — instant play reaches WeChat's 1.3 billion monthly active users. Cocos Creator provides native support for building WeChat Mini Games, allowing developers to write once and publish directly to the WeChat ecosystem. Combined with the WeChat open data domain, social features such as friend leaderboards can be implemented to significantly improve user retention and viral reach.
