# 平台简介

微信小游戏是基于微信生态的轻量级游戏分发平台,无需下载安装、即点即玩,覆盖微信 13 亿月活用户。Cocos Creator 通过原生支持微信小游戏构建,开发者可一次开发,直接打包发布到微信生态;配合微信开放数据域,可实现好友排行榜等社交玩法,显著提升用户留存与传播效率。

## 平台网址

- <https://mp.weixin.qq.com/>(微信公众平台 - 小游戏管理后台)
- <https://developers.weixin.qq.com/minigame/dev/guide/>(微信小游戏开发文档官网)
